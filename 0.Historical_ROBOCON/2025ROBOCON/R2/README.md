# ROBOCON2025"飞身上篮"R2投篮机器人代码

## 一 . R2_classic_H7
测试投篮数据时使用的版,没有根据距离自动发射篮球命令

## 二 . R2_classic_H7_Auto
正式比赛时使用的一版,可以配合上位机的拟合数据适应距离投篮

## 三 . R2_short_ball_v1
前期测试投篮的代码,使用的横向摩擦轮,和后期比赛不相关
